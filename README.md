# Ollline.design — сайт-визитка

Статичный сайт: HTML, CSS и JavaScript без фреймворков и базы данных. Работает на любом хостинге.

## Файлы

| Что | Где |
| --- | --- |
| Страницы | `index.html`, `404.html` |
| Оформление и логика | `styles.css`, `script.js`, `gallery.js` |
| Исходные фото и видео | `Портфолио/` (на сайт не выгружается) |
| Сжатые фото и видео для сайта | `media/` (создаётся скриптом) |
| Иконки и картинка для соцсетей | `icons/` |
| Для поисковиков | `robots.txt`, `sitemap.xml` |
| Настройки хостинга | `.htaccess`, `_headers`, `netlify.toml`, `vercel.json` |
| Скрипты | `tools/build_media.py`, `tools/build_site.py` |

## Две команды

Пересобрать фото и видео после того, как добавили файлы в `Портфолио/`:

```bash
python tools/build_media.py
```

Собрать сжатую версию сайта для выгрузки на хостинг (создаст папку `dist/`):

```bash
python tools/build_site.py
```

Выгружать на хостинг нужно **содержимое папки `dist/`**. Папки `Портфолио/` и `tools/` туда не попадают.

**Важно:** перед первой сборкой откройте `tools/build_site.py` и впишите свой домен в строку `SITE_URL`. Скрипт сам подставит его во все служебные ссылки.

## Что по SEO уже сделано в коде

**Техническая часть**
- Фото сжаты в WebP, у каждого есть маленькая копия для телефонов (`srcset`), видео в H.264 с быстрым стартом.
- Превью на первом экране существует в трёх размерах (1,2 / 3,8 / 9,7 МБ), сайт выбирает по экрану. При медленном интернете, режиме экономии трафика или на слабом устройстве видео не грузится совсем, остаётся картинка.
- Адаптивная вёрстка: проверено на 375, 768, 1100, 1440 и 1550 px.
- Кэширование и сжатие настроены в `.htaccess` (Apache), `_headers` (Netlify, Cloudflare) и `vercel.json`. Медиа кэшируются на год, HTML не кэшируется.
- Переадресация на HTTPS и с www на без www прописана в `.htaccess`.
- `robots.txt` закрывает служебные папки и указывает на карту сайта, `sitemap.xml` создан.
- Страница 404 оформлена в стиле сайта и ведёт обратно на разделы.
- Ссылки внутри сайта проверены, битых нет. Дублей страниц нет: сайт одностраничный, прописан `canonical`.

**Содержание и структура**
- Заголовок страницы и описание переписаны под запросы: дизайн интерьера, 3D-визуализация, планировки, рабочие чертежи.
- Один `H1`, дальше `H2` по разделам и `H3` внутри. Для поисковиков в `H1` добавлена скрытая расшифровка.
- Микроразметка Schema.org (`ProfessionalService`, `Person`, `WebSite`): услуги, контакты, ссылки на Telegram и Instagram.
- Разметка Open Graph: при отправке ссылки в мессенджер показывается обложка `icons/og-cover.jpg`.
- Добавлен раздел «Как я работаю» с четырьмя этапами и перелинковкой на портфолио.
- У всех фото есть описания (`alt`) с типом работы и направлением.

## Что нужно сделать вам (без этого я не могу)

1. **Домен и хостинг.** Купить домен, выбрать хостинг. Подойдут Netlify, Vercel, Cloudflare Pages (бесплатно) или любой обычный хостинг с Apache.
2. **SSL-сертификат (HTTPS).** На Netlify, Vercel и Cloudflare включается одной кнопкой и бесплатно. На обычном хостинге обычно есть бесплатный Let's Encrypt в панели управления.
3. **Телефон для WhatsApp.** Контакты на сайте настоящие: WhatsApp и Instagram `@ollline.interiors`, почта `ollline.design@gmail.com`. Но ссылка на WhatsApp работает только с номером телефона (формат `https://wa.me/420777123456`). Пришлите номер или вашу личную ссылку-приглашение из приложения, я подставлю.
4. **Домен в коде.** Указать его в `tools/build_site.py` (строка `SITE_URL`), иначе в `canonical`, `sitemap.xml` и соцсетях останется `olline.design`.
5. **Панели вебмастера.** Добавить сайт в Яндекс.Вебмастер и Google Search Console, загрузить туда `sitemap.xml`.
6. **Аналитика.** Завести Яндекс.Метрику или Google Analytics и прислать мне код счётчика, я аккуратно встрою (до этого никаких сторонних скриптов на сайте нет, и это хорошо для скорости).
7. **Карты и справочники.** Яндекс.Бизнес, Google Карты, 2ГИС, профильные каталоги дизайнеров. Нужен город и, желательно, телефон.
8. **Внешние ссылки и упоминания.** Публикации у партнёров, профили на Houzz, Behance, Pinterest со ссылкой на сайт. Это делается вручную и постепенно.

## Что стоит добавить на сайт позже

- **Ответы на частые вопросы** (сроки, этапы, стоимость, работа удалённо). Это сильный сигнал для поиска, но ответы должны быть вашими, придумывать их за вас я не стал.
- **Кейсы проектов**: 3–5 отдельных страниц «было / стало / что сделали». Под такие страницы поиск даёт много трафика.
- **Отзывы клиентов** с именами и проектами.
- **Форма заявки** вместо простых ссылок (нужен сервис приёма заявок, например Formspree, или почта на своём домене).
